# 프로 카메라

갤럭시 Z Fold8용 기본 카메라 앱.

- 폰에 있는 카메라를 모두 찾아 전환 (후면 / 전면 / 전면 2 …)
- 24 / 30 / 60fps (폰이 막은 프레임은 건너뜀), 1080p H.264
- 화이트밸런스 잠금, AE 잠금, 탭 초점·노출 (길게 누르면 자동)
- 화각 5개 (35mm 환산 14 / 24 / 35 / 50 / 85) — 누르면 부드럽게 줌
- 텐션 줌 레버: 위로 밀면 줌인, 당기면 줌아웃, 많이 밀수록 빠름
- DSLR식 정보: 셔터속도, ISO, 색온도(추정), 해상도·프레임, 남은 녹화 시간, 배터리, 히스토그램, 수평계
- 세로: 버튼 아래 / 가로: 버튼 오른쪽
- 저장: DCIM/ProCamera

APK는 GitHub Actions가 빌드해서 Releases의 `latest`에 올립니다.
